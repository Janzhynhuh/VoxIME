# VoxIME 声语 - 桌面免安装版

1. 双击 `VoxIME.exe` 启动，不需要安装。
2. 首次运行如出现 Windows SmartScreen，点“更多信息”再点“仍要运行”。
3. 配置、日志、历史保存在 `%APPDATA%\VoxIME`，升级/替换程序目录不会丢。
4. 解压到普通目录即可；不要放进带 Low 完整性标签的沙箱/仓库工作区运行，否则可能出现无托盘、日志不写。
5. API Key 明文保存在 `%APPDATA%\VoxIME\config.json`，请勿分享该文件。
6. 设置 → 通用 → 配置导入导出：可备份/迁移服务、热键、录音、桌宠等设置；导出时可选择是否包含 API Key，导入前会自动备份当前配置。
7. 桌宠默认使用模型自然呼吸/眨眼/物理；`Animation/IDLE` 是一次性动作，默认不作为待机循环。需要时在「待机动作组」里显式选择。
8. Cubism 在动作播放期间会跳过自动眨眼；想恢复眨眼/耳朵，关闭待机动作或不要让一次性动作常驻。

当前构建的版本、提交和时间见同目录 `BUILD.txt`。
