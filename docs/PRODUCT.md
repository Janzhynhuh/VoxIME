# VoxIME 产品说明书（PRD）

> 版本：v0.1 规划稿 · 定位：Windows 桌面端「语音输入 + 桌宠」工具

## 1. 背景与问题

- 键盘输入中文仍有速度瓶颈，尤其长句、口语化表达、双手被占用（编程、设计、会议记录）时效率低。
- 系统自带语音输入（Win+H）识别由微软垄断、不支持自定义厂商，也不支持本地离线模型；商业输入法的语音功能绑定自家云服务，无法接入企业私有 ASR / 自建大模型。
- 中文互联网用户（二次元、VTuber、桌宠爱好者）希望桌面有一个"活"的虚拟形象，但目前语音输入与 Live2D 桌宠是两个割裂的工具。

**机会**：做一个"语音输入 + 可插拔 ASR + Live2D 桌宠"的桌面小工具，把识别能力选择权交给用户，同时提供情绪价值。

## 2. 目标用户

| 画像 | 场景 | 关键诉求 |
|---|---|---|
| 效率型用户（程序员/产品/运营） | 长文档、聊天、代码注释口述 | 快、准、任何输入框可用、少打断 |
| 隐私敏感用户（法务/医疗/政企） | 内部资料口述 | 本地离线、数据不出本机 |
| 多模型玩家（AI 爱好者） | 折腾各家 ASR/大模型 | 自定义 BaseUrl/模型、多配置快速切换 |
| 二次元/桌宠用户 | 桌面陪伴 + 语音互动 | Live2D 形象、口型同步、状态联动 |
| 内容创作者 | 口播转文字、直播字幕辅助 | 低延迟、可编辑、历史可回溯 |

## 3. 产品定位与差异化

一句话：**「一个能换语音模型、能养 Live2D 老婆的 Windows 语音输入法」**。

| 维度 | 系统语音输入 | 商业输入法语音 | VoxIME |
|---|---|---|---|
| 厂商可换 | ❌ | ❌ | ✅ OpenAI 兼容/小米 MiMo/DashScope/腾讯/讯飞/本地 CLI |
| 本地离线 | 部分 | 部分 | ✅ whisper.cpp/FunASR/sherpa-onnx |
| 任意输入框 | ✅ | ✅ | ✅（管理员窗口例外） |
| Live2D 桌宠 | ❌ | ❌ | ✅ 模型自备、状态/口型/眼动联动 |
| 可定制/可扩展 | ❌ | ❌ | ✅ 开源、适配器即插即用 |
| 隐私 | 系统云 | 厂商云 | 本机保存 + DPAPI + 本地模式 |

## 4. 功能需求

### P0（v0.1 必须）
1. 全局热键：按住说话、按下切换两种模式，热键可配置（键盘组合、F1-F24、鼠标侧键/中键）；录音中可取消。
2. 录音：麦克风设备选择、16kHz 单声道、能量 VAD、静音自动结束、最长时长限制、提示音。
3. 多厂商 ASR：OpenAI 兼容接口（文件）、OpenAI Chat Audio（MiMo/DashScope）、腾讯云、讯飞、本地 CLI、Mock；可配置多套服务并切换默认。
4. 上屏：剪贴板粘贴优先、模拟输入兜底、可配置预览确认、自动追加空格/回车、术语替换、剪贴板还原。
5. 结果展示：HUD 状态条（聆听/识别/错误）、实时麦克风电平、预览编辑、插入/复制/取消。
6. 历史：本地记录（时间/文本/服务/时长/延迟），可复制、清空。
7. Live2D：透明置顶窗口、加载 Cubism 3/4 模型、待机动画、状态联动、口型（麦克风）、眼动跟随、气泡字幕、点击穿透、位置/大小/透明度/缩放；无模型时兜底形象。
8. 设置中心：服务/录音/上屏/桌宠/朗读/通用六个页签，保存即生效；首次启动引导。
9. 托盘：显示/隐藏桌宠、暂停热键、设置、历史、日志目录、退出；开机自启。
10. 安全：API Key DPAPI 加密；配置/历史/日志本地方案；日志脱敏。

### P1（v0.2+）
- 流式识别（边说边出字）、增量上屏。
- 多服务自动降级/并发竞速（准确率与延迟权衡）。
- 热词/自定义词典、标点增强、口语书面化。
- 云 TTS + viseme 口型、桌宠待机随机动作/互动（点击、拖拽）。
- 识别结果 LLM 润色（可选，接 OpenAI 兼容）。

### P2（v0.3+）
- TSF 输入法注册（语言栏可见）、候选词/标点选择。
- 多语言识别与 UI（英/日）。
- 插件化适配器（DLL/脚本市场）、配置导入导出。
- 自动更新与代码签名。

## 5. 核心交互流程

```
[任意应用输入框] 按住 Ctrl+Alt
      ↓
HUD 出现：🎙 聆听中（电平环呼吸）   桌宠：聆听动作 + 口型
      ↓ 松开
HUD：识别中（转圈）                 桌宠：思考动作
      ↓
文字粘贴到光标处 + HUD 显示结果      桌宠：气泡显示 + 朗读/口型（可选）
      ↓ 自动消失
```

异常路径：
- 没有检测到语音 → HUD 提示"没有检测到语音"，2s 消失。
- 识别失败 → HUD 红色提示 + 托盘气泡，桌宠 Error 动画，3.5s 恢复。
- 上屏失败 → 文本自动复制到剪贴板，HUD 提示"已复制，请手动粘贴"。
- 用户取消（Esc/再次按切换键）→ 立即停止、丢弃本轮。

## 6. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 待机内存 < 150MB；录音期间 CPU < 8%（不含厂商网络等待）；桌宠 30~60fps 且不阻塞 UI；热键响应 < 50ms |
| 延迟 | 松开热键到文字上屏：本地 CLI（small 模型）< 2s；云端 < 3s（视网络） |
| 兼容性 | Windows 10 1809+ / 11 x64；普通/管理员权限均可启动；兼容 Win11 深色模式与 125%/150% DPI |
| 稳定性 | 7×24 小时运行不崩溃；麦克风热插拔后可恢复；网络失败不影响热键与设置 |
| 隐私 | 默认不联网；仅调用用户配置的服务；无遥测/统计 |
| 可维护性 | 新增厂商只需实现接口 + 注册，不改 UI；核心逻辑单测覆盖 |
| 可访问性 | 全键盘可操作（热键/托盘/设置 Tab 顺序）；状态有文字提示不只靠颜色 |

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 厂商 API 变更/下线 | 识别失败 | 适配器隔离 + 统一错误提示 + 多服务可切换；文档标注"以官方为准" |
| 管理员窗口无法注入 | 用户觉得"不灵" | 文档说明 + 以管理员运行 + 剪贴板兜底 + HUD 提示 |
| Live2D 许可限制 | 商业分发风险 | 只做"用户自备模型"加载；示例模型仅开发期使用；文档明确许可提示 |
| 系统自带语音输入免费且好用 | 获客难 | 差异化：可换模型、本地离线、桌宠、开源可定制 |
| WebView2 缺失/显卡兼容 | 桌宠黑块 | 自动降级 WPF 兜底形象；文档提供 Runtime 安装指引 |
| 杀毒软件误报（模拟按键/钩子） | 安装受阻 | 不签名初期在 FAQ 说明；后续代码签名 + 提交白名单 |
| 热键冲突 | 功能看似失效 | 设置页提供冲突检测提示与多种预设；托盘"暂停"状态可见 |

## 10. 成功指标（上线后）

- 首次配置成功率 ≥ 80%（从启动到成功测试识别）。
- 每日活跃用户次日留存 ≥ 40%。
- 识别失败率（含网络/厂商错误）≤ 5%，失败后 10s 内可恢复。
- 用户可平均配置 ≥ 1.5 个识别服务（体现"可插拔"价值）。
- 崩溃率 < 0.1%/日。
